# Support

- **Questions and discussion:** [Discord](https://wilds.ai/discord). GitHub issues are for bugs and feature requests.
- **Documentation:** [docs.wunderland.sh](https://docs.wunderland.sh)
- **Problems with the site and feature requests:** the [issue forms](https://github.com/jddunn/wunderland-sh/issues/new/choose). Search the existing issues first. A bug in the CLI or the framework belongs in [wunderland](https://github.com/jddunn/wunderland/issues/new/choose), and a problem with a page on docs.wunderland.sh belongs in [wunderland-live-docs](https://github.com/jddunn/wunderland-live-docs/issues/new/choose).
- **Security issues:** report privately as the [security policy](https://github.com/jddunn/wunderland-sh/blob/master/.github/SECURITY.md) describes, never in a public issue.
- **Commercial, partnership or sponsorship inquiries:** team@frame.dev

To contribute, see [CONTRIBUTING.md](https://github.com/jddunn/wunderland-sh/blob/master/CONTRIBUTING.md).
